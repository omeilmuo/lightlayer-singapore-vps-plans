可查到的资料里没有一本正经解释这两个系列的区别。库存站把它们并列收录，配置、价格、计费周期完全一致，CPU 型号、上游运营商、线路、适用场景一个字都没写。

能观察到的差异只有两点。NAT 版比同系列常规版贵 $5.00/月，$12 对 $7；两个版本的 IPv4 字段都标“Yes”。

第二点值得单独说。按行业惯例，NAT 机型给的多是共享 IPv4，出站要经过地址转换，独立地址另算或者干脆没有。这两个页面把常规版和 NAT 版的 IPv4 都写成“Yes”，却没区分“独立”和“共享”。可能只是字段被简化，也可能 NAT 版另配了独立地址，现有资料不足以判断。别按“贵 $5 一定多了什么”去推。

下单前值得直接问商家的几个问题：

1. NAT 版的 IPv4 是独立地址还是共享地址？共享的话几个人共用？
2. 共享 IP 能不能做 80/443 入站？端口固定还是随机分配？
3. VP 和 VG 两个系列的 CPU 型号、线路、超售比例有没有区别？
4. 同价的 VP02 和 VP04、VG02 和 VG04，编号不同差在哪？

最后一问来自表里的现象：VP02 与 VP04 同价同配，VG02 与 VG04 也同价同配，页面没写清编号含义。它可能是上架批次、机柜位置，也可能只是收录重复，只有商家能给出准话。不要因为编号大就以为配置更高。
